01 Structure

Built on Client First

  • Every page runs Navbar, sections, Footer. Each section uses padding global and the 12 column grid global.
  • Text uses Client First classes, such as heading style h2 and text color secondary. Most edits are a class swap.
  • Home, Studio and Contact come in three layouts. Keep one of each, set the others to draft and update the Navbar and Footer links.

One section on Services

  1. Label: text style label
  2. Heading: heading style h2, muted half in a text color tertiary span
  3. Collection List inside padding global and grid global
  4. Links: text style link

The Template Tour, a preview helper

  1. Switch the three Home layouts
  2. Open Studio and Contact in each layout
  3. Jump to every other page
  4. The Explore Vika pill. Delete Template Tour from the Footer component before launch.

02 Colour and type

Change the brand in Variables

  • Colours, radius and sizes live in the Variables panel.
  • Elements use semantic colours such as Text Primary and Accent Primary. Point them at another ramp step to recolour.
  • Edit Burgundy 700 (#4C2218) to change the accent everywhere.
  • Turn a section dark by applying the Dark mode to its class.
  • Spacing and type sizes have Tablet and Mobile modes, so one change covers every breakpoint.
  • Familjen Grotesk sets text and DM Mono sets labels, both in Site settings, Fonts.

Variables panel in the Designer

  1. Collections: Base for colour, Layout for spacing, Typography for type
  2. Burgundy 700: change it to rebrand the accent
  3. Dark mode: the values dark sections use
  4. Semantic colours point at ramp steps

01 Interactions

How to Edit GSAP Animations

Motion runs on Webflow Interactions, which are built on GSAP. Each is named page first, then action, such as Pricing / Show yearly prices. Global means it runs on every page. Three small effects use GSAP in custom code, covered below.

  1. Open the Interactions panel.
  2. Pick an interaction by name.
  3. Select an action to change its duration, delay or ease.
  4. To skip it on one breakpoint, add a conditional playback rule.
  5. To remove it, delete the interaction. The element shows in place.
  6. Keep the reduced motion rule on anything you add.

Interactions panel in the Designer

  1. Every interaction, by name
  2. Trigger and actions of the selected one
  3. Reduced motion rule: skip to end
  4. Timeline: drag or select an action to change timing

03 Custom code

GSAP in custom code

Three blocks in Site settings, Custom code, Footer code. Each starts with a comment naming its page and action, such as GSAP / Global / Counters count up on scroll.

Office clocks

data-clock-tz sets the city on each clock row.

Menu hover

Dims the other menu links and nudges the active one.

Counters

Add data-count to any figure to count it up.

Key settings

// Vika counters: speed, easing and start point
g.to(o, { v: to, duration: 0.8, ease: 'power3.out',
  scrollTrigger: { trigger: el, start: 'top 85%', once: true } });
// Vika menu hover: speed, dim level and nudge
var d = still ? 0 : 0.4;
g.to(l, { opacity: active && !on ? 0.5 : 1, x: on && !still ? 14 : 0,
  duration: d, ease: 'power3.out', overwrite: 'auto' });
// Vika office clocks: second hand tick
g.to(k.s, { rotation: deg, duration: 0.35, ease: 'back.out(3)', overwrite: true });

Remove a block

  1. Open Site settings, Custom code, Footer code.
  2. Delete the block from its comment to its closing script tag.
  3. Save and publish. Figures and times then show as typed.

Before launch

Seven checks before you go live

  • Replace every image and the sample team.
  • Rewrite fees, deadlines and articles. Check tax dates against current FTA and HMRC guidance.
  • Write an SEO title and description for every page and CMS template.
  • Replace the sample Privacy Policy with your own.
  • Connect your calendar tool if you take online bookings.
  • Draft or delete this page, Overview, Licenses and Changelog, and delete the Template Tour.
